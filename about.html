About Railway Ticket Booking

Railway Ticket Booking Simulation is a first-year Web Designing mini project.

This project is developed using HTML, CSS and JavaScript. It provides a simple interface for railway ticket booking.

Project Features

  • Railway ticket booking form
  • Passenger information
  • Journey date selection
  • Travel class selection
  • Fare calculation
  • PNR number generation
  • Booking confirmation

Technologies Used

HTML: Used to create the structure of the website.

CSS: Used for designing, layout and colours.

JavaScript: Used to add booking functionality, fare calculation and PNR generation.

Project Purpose

The purpose of this project is to demonstrate basic web designing concepts and JavaScript functionality through a railway ticket booking simulation.

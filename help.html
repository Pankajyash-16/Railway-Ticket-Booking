Railway Ticket Booking Simulation - User Guide

1. How to Book a Ticket?

To book a railway ticket, open the Book Ticket page and enter your journey and passenger details.

  • Select the From Station.
  • Select the To Station.
  • Select the journey date.
  • Select the travel class.
  • Select the number of passengers.
  • Enter details of each passenger.
  • Click on the Search & Book Train button.

2. Passenger Details

You can select the required number of passengers. Each passenger can have different personal details.

  • Passenger Name
  • Age
  • Gender
  • Separate seat number

3. Railway Classes

The project provides different railway travel classes. The fare depends on the selected class.

  • Sleeper (SL)
  • AC 3 Tier (3A)
  • AC 2 Tier (2A)
  • First AC (1A)

4. Fare Calculation

The total fare is calculated automatically according to the selected travel class and number of passengers.

Total Fare = Fare per Passenger × Number of Passengers

5. Ticket Confirmation

After successful booking, the system generates ticket information for the passengers.

  • PNR Number
  • Ticket ID
  • Passenger information
  • Journey details
  • Travel class
  • Seat number
  • Total fare

6. PNR Number

A PNR number is generated for the booking. It can be used as a reference for the generated booking information in this simulation.

7. Different Seats for Passengers

When multiple passengers are selected, the system generates a separate seat number for each passenger.

For example, passengers may receive seats such as S1-01, S1-02, S1-03, etc., depending on the selected travel class.

8. Important Instructions

  • From and To stations should not be the same.
  • Enter correct passenger information.
  • Select all required fields before booking.
  • Check the journey date carefully.
  • Check passenger details before submitting.
  • Keep the generated ticket information for reference.

9. Mobile Phone Usage

This website is designed to work on both computer and mobile screens. For a better experience on mobile, use a modern web browser and keep the device in portrait mode when required.

10. About This Project

Railway Ticket Booking Simulation is a B.Tech First Year mini project developed using HTML, CSS and JavaScript. It demonstrates the basic working of an online railway ticket booking interface.

11. Technologies Used

  • HTML - Structure of the website
  • CSS - Design and responsive layout
  • JavaScript - Booking logic and ticket generation
